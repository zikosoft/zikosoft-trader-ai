# Replay demo dataset

`dataset.json` is a deterministic **synthetic UI fixture**
for demonstrating the Replay screen before an Alpaca Paper account is connected.
It is not an Alpaca export, must not be presented as historical market evidence,
and is not used by the Paper execution pipeline.

The file contains one complete US session (390 one-minute candles, UTC
13:30–19:59) for AAPL, MSFT and SPY. Its checksum was validated with the
project's `shared.replay_market_data.load_dataset` implementation.

Phase 2 adds a read-only options-path preview to the Replay screen. It is
derived deterministically from the current AAPL candle using the existing
Moving Average Crossover strategy. Any displayed option contract, quote,
premium and maximum loss is synthetic and is prominently labeled as such. No
agent, MCP, Claude call, risk decision or broker order is produced.

When an Alpaca account is available, replace this fixture with a real dataset
generated by `scripts/fetch_replay_dataset.py` and keep the same destination.
